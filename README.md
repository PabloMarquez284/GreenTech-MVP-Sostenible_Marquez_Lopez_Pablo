# GreenTech-MVP-Sostenible_Marquez_Lopez_Pablo

## 📌 Descripción
Refactorización de una landing page para hacerla más ligera, rápida y sostenible.

## ❌ Problema
El código original utilizaba librerías innecesarias como Bootstrap y jQuery, aumentando el peso y el consumo de recursos.

## ✅ Solución
* Eliminación de librerías externas
* Uso de HTML y CSS nativo
* Optimización de la imagen (local)
* Código más limpio y simple

## ⚡ Resultados
* Menor peso de la web
* Carga más rápida
* Menor consumo de energía

## 🌍 Conclusión
Reducir dependencias mejora el rendimiento y hace el software más sostenible.
